Universal loader: any executable format, any OS

src/loader.rs reads ELF, PE, Mach-O (including fat binaries), and falls back to
a raw flat image, handing the rest of the pipeline the same thing regardless of
source: entry, executable segments, data segments, and what symbols the file
carries. The x86 decoder and the machine never knew about containers; only the
loader did, and now it reads all of them.

The container is universal; the instruction set is x86-64. A code segment that
is not x86 fails to decode instruction by instruction and the walk reports how
far it got, rather than being refused at the door.

emit, words, the auditor and symbol resolution all route through the loader now.
Verified: a PE (7z.exe) lifts and audits where before it read as no sections;
ELF execution parity with native is unchanged, zero mismatches across all five
optimisation levels.
