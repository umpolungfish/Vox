README: rewrite for the Rust crate that runs the glyphs

The document described vox.py. It now describes what V⊙x is: a single Rust crate
with no external crates that reads any executable container (ELF, PE, Mach-O,
fat, raw), decodes x86 with its own operand decoder, recompiles each instruction
to a glyph plus executable payload, and runs the word in a machine that gets
native's answer. The verbs are the installed binary's (run, imasm, word, disasm,
audit, verdict, evm, wasm), the pipeline is the four real parts (loader, decoder,
recompiler, machine), and the lanes say plainly which execute and which lift and
verdict. No process-log register, no em-dashes.
