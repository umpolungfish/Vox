vox compile <seq> runs the full RNA<->protein pipeline both ways, natively in this binary, with real fold info on both ends.

genetic::lift_rna/lift_protein were never the right foundation for this: they keep only the twelve promoted residues by design (the eight ground-layer amino acids are silent, since that lift answers one question — does the glyph word close). A real reverse translation or a real fold needs every residue a protein actually has. So this is three new modules, all full-fidelity, all reusing genetic_table::CODON and genetic::dialect_override rather than reimplementing the genetic code:

protein.rs — the forward and reverse pipelines. translate_full keeps every residue in translation order, promoted or not. reverse_translate_full picks a real Frobenius-preferred codon per residue (ported from red-hot_rebis's _compute_preferred_codons: prefer the position-3 C variant within whichever exact-stratum or four-fold-degenerate tier the amino acid's codons fall into), and reports the real degeneracy, every codon count and the product across the chain.

fold.rs — Chou-Fasman secondary structure and heuristic hydrophobic/disulfide/ionic tertiary contacts, the same algorithm mOMonadOS's rebis::fold already ports from the same source, here keyed on the plain &str amino acid names this crate already uses instead of a foreign enum.

fold3d.rs — the piece that was still missing everywhere: real 3D backbone coordinates. A straight port of red-hot_rebis's B4-Ramachandran-NeRF construction (the exact 16-entry table, the same bond lengths and angles, the same internal-to-Cartesian placement) and its PDB writer. No external crates, matching this crate's own rule: sin/cos/sqrt are hand-rolled (Taylor series, Newton's method) rather than pulling in libm. One real correction on the way in: the Python source indexes its B4 path per-nucleotide but reads it with the per-residue loop index, an off-by-factor-of-3 mismatch — here every residue gets its own real B4 (the first position of the codon that produced it), so the lookup is direct instead of carrying that mismatch forward.

Checked, not assumed: the PDB this writes round-trips through this crate's own reader, genetic::protein_from_pdb, called directly in a test and confirmed live from the shell binary (vox compile ... --pdb, then vox pdb on the result) — same residues back out, right glyph word, right verdict. Ten new tests, all passing. Direction auto-detects from the input alphabet: pure A/C/G/T/U reads as nucleic acid, anything else as protein codes.
