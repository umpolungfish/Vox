V⊙x reads the other lanes a biomolecule arrives in

A gene was the only text it could read. A peptide arrives as residues, a deposited
structure as coordinates, and a small molecule as SMILES, and each of them lifts to
the same twelve and is verdicted by the same engine.

--peptide takes one-letter or spaced three-letter codes. --pdb takes a structure and
reads one residue per resolved alpha carbon, with --chain to restrict it, which is
reading what the lossy render kept. --smiles types a molecule by functional-group
census, chirality-aware, and reports the CIP word on chirality separately, since an
achiral census cannot see what distinguishes stereoisomers.

And the reading now takes a dialect. The vertebrate mitochondrial code differs from
the standard one in four codons, and reading a mitochondrial gene with the standard
table terminates it early: cytochrome c oxidase subunit I stops after three marks and
reads N, and in its own dialect it runs the full length and reads B. One of the four
differences matters to the alphabet directly, since UGA is a terminator in the
standard code and tryptophan here, which is the mark that closes a reading.

The Rust core carries the same two: lift_peptide, and lift_rna_dialect with the
override table beside it, so the kernel reads what the Python lane reads.
