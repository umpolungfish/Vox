Load the constructor/destructor array sections

The ELF loader took PROGBITS only, so INIT_ARRAY, FINI_ARRAY and PREINIT_ARRAY
(types 14/15/16) never reached memory and the C runtime read a zero table and
called address 0. Loading them lets a lifted program run its constructors
before main.

This closes the self-host: vox built static-musl, lifted to the twelve marks
and run in imasm_vm, executes `vox verdict ⊢⊞⊤⊣` and prints `verdict N`, exit 0,
identical to native vox. g-momonados still boots byte-identical, so the narrow
load carries the constructors without disturbing the proven run.
