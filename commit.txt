Add the hex lift lane: vox hex <hex>

Lifts a raw machine-code hex value stream, the delta half of the vox pair
pointed at inline hex instead of a file. Decodes the hex to bytes, loads them
as a flat code image, walks the control flow, recompiles each function to its
glyph word, and reads the closure verdict of each, the same pipeline vox self
runs on a file. Reuses the tolerant hex decoder (lanes::from_hex, now public)
that the evm and wasm lanes already use.

Verified: a small function push rbp/mov/xor/pop/ret lifts and reads N; a
conditional branch cmp/jne/xor/ret reads T with the fork and fuse reconnecting
(⊢⊤∈⊞∋⊣); the shuffle control (permuted bytes) decodes to different words, so
the reading tracks the bytes and is not an artifact. This is the
lifting_hex_values_with_vox ob3ect made operational.
