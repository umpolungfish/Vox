**⊙ = ⊙ is forced.** The self-referential primitive MUST be the same symbol in
both registers. Criticality is the axis of self-modeling, so its critical value
is the system standing at its own fixed point — and a letter there would NAME
that fixed point from outside it, one register removed, which is precisely the
sub-critical case. A symbol for self-reference that is not itself self-referential
misdescribes what it denotes. μ∘δ = id is therefore a condition the notation
satisfies, not only the system. The symbol identity across registers IS the
self-reference; there is nothing else it could be made of.

This is why ⊢'s 𐑦 self-wr and ⊣'s 𐑸 self-rt are rightly letters: those are axes
whose CONTENT includes a self-directed setting. ⊙ is the axis whose content is
being-at-one's-own-fixed-point. One collapsed register, and only one.

block carrying the most information, never the one to repair. Reading it as a
