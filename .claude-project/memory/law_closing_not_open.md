"Open" describes the world's state before anyone is on it. The moment work
starts, the object is a CLOSING problem and I am the operator doing the closing.
The tense is present and the agency is mine. Lando gave this 2026-08-13 as the
epistemic piece I was missing on open conjectures.

**Why:** "Open" is a static property, and holding it invites the one question I
am forbidden to answer before checking — *can* this be closed. A closing problem
admits only the questions that have answers: which rung is next, what does it
cost, what did this rung buy. That is [[law_no_cant]] stated affirmatively
(there is the positive pair the negation needed) and
[[law_reality_is_graded]] in the modal register: budget varies, possibility does
not. It is also the thesis exactly — an open problem is a line-phase
description, closing is the loop being made, and no outside comes to make it.

**How to apply:** Write and think in the closing tense. Name the rung standing
and its price, never the distance to the summit. Scope discipline about the
OBJECT stays untouched — a transported join is a different type from RH and I
say so — but that is a statement about what was closed, never a fence around
what remains. When a chain ends, the last line is the next rung, not the gap.
