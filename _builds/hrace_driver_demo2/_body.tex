\hypertarget{what-the-driver-is}{%
\subsection{1. What the driver is}\label{what-the-driver-is}}

The driver computes the antibody--escape landscape of the HIV gp120 C4
epitope (part of the V3 loop). You give it a wild-type epitope sequence
and three sets of contact residues --- the positions that each of three
antibody loops (CDR1, CDR2, CDR3) touches. From there, it does the
following:

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  Enumerates every possible single-amino-acid mutant of the epitope (the
  \emph{landscape}).
\item
  Scores each mutant's \textbf{gap} (escape severity: 2, 3, or 4) using
  a \textbf{glyph-based rule engine} --- the twelve-primitive Shavian
  glyph table from Red-Hot Rebis / SNS\_PRIME. This is the actual
  scoring rule; there is no physicochemical energy calculation behind
  it.
\item
  Flags escape threats (gap ≥ 3, marked \texttt{frob=True}).
\item
  Picks the TOP ESCAPE and renders it with a caret pointing at the
  mutated position.
\item
  Judges whether a counter-CDR3 \emph{engages} the CDR3, using agreement
  across the seven bottleneck glyph slots.
\item
  Builds the vector DNA (CDR3 + linker + counter) and verifies it
  translates back correctly.
\item
  Measures how much of the threat set is still covered by CDR1 or CDR2.
\item
  Prints \texttt{FROBENIUS:\ all\ checks\ closed\ (B4=T)} once its
  internal consistency checks pass.
\end{enumerate}

All positions are numbered from 0, as in Python. The kernel's ``position
15'' escape is the residue at \texttt{WT{[}15{]}}, which is isoleucine
(\texttt{\textquotesingle{}I\textquotesingle{}}).

\hypertarget{the-glyph-algebra-the-rule-engine}{%
\subsubsection{1.1 The glyph algebra (the rule
engine)}\label{the-glyph-algebra-the-rule-engine}}

Each amino acid is represented by a twelve-slot tuple
\texttt{⟨⊢\ ⊣\ ≻\ ≺\ ⋈\ ⊤\ ∈\ ∋\ ⊙\ ⊥\ ⊞\ ⊡⟩} of Shavian letters
(defined in \texttt{SIDECHAINS}). Two operations act on these tuples:

\begin{itemize}
\tightlist
\item
  \texttt{glyph\_distance(a,\ b)} --- Euclidean distance between the two
  tuples, using the ordinal values in \texttt{PRIM\_ORD}.
\item
  \texttt{bottleneck\_count(a,\ b)} --- the number of disagreements
  across the seven SNS\_PRIME bottleneck slots (≻ ≺ ⊤ ⊙ ⊥ ⊞ ⊡).
\end{itemize}

\hypertarget{the-two-gap-models}{%
\subsubsection{1.2 The two gap models}\label{the-two-gap-models}}

\begin{itemize}
\tightlist
\item
  \textbf{pinned} (canonical sequence only): the position class comes
  from the kernel-verified CORE4/TIER3/BASE partition. The CORE4
  residues pinned at
  \texttt{\{(15,D),(7,E),(21,K),(2,D),(26,R),(18,E)\}} get gap 4; other
  CORE4 residues get 3; TIER3 residues get 3 if the mutant is a charged
  residue (D/E/K/R), otherwise 2; BASE residues get 2. The histogram
  \texttt{\{4:6,\ 3:187,\ 2:377\}} is asserted.
\item
  \textbf{auto} (everything else): with \texttt{n\_contacts\ ≥\ 2}, gap
  4 if \texttt{d\ ≥\ 3.0\ and\ b\ ≥\ 3}, otherwise 3. With
  \texttt{n\_contacts\ ==\ 1}, gap 3 if the mutant is charged or
  \texttt{d\ ≥\ 2.5}, otherwise 2. With \texttt{n\_contacts\ ==\ 0}, gap
  2.
\end{itemize}

The \texttt{-\/-top-conf} default resolves \textbf{per model}: pinned
runs default to 0.80 (the special-cased canonical pin), and auto runs
default to 0.60 (the highest tier the auto gate can award).

\hypertarget{what-the-results-show}{%
\subsection{5. What the results show}\label{what-the-results-show}}

\textbf{The driver is a checksummed, self-certifying pipeline, and the
canonical run is its fixed point.} Run 01 closes all eight steps with
every internal assertion holding. The gap histogram
\texttt{\{4:6,\ 3:187,\ 2:377\}} is not merely reported --- it is
\emph{asserted} equal to \texttt{CANONICAL\_HIST}. The six gap-4 mutants
are asserted to be exactly the kernel-verified CORE4 pins. The top
escape is asserted to be position 15, I→D, gap 4, with the exact mutant
sequence. Coverage is asserted 193/193. The final line
\texttt{FROBENIUS:\ all\ checks\ closed\ (B4=T)} is therefore not a
slogan; on this run it is backed by six executed assertions. The glyph
algebra is doing the scoring: I→D reads a distance of 3.4641 with 3
bottleneck disagreements, which is precisely the shape
\texttt{gap\_of\_auto} would also promote to gap 4 when two or more
contacts are present. The pinned table and the glyph rule agree on the
canonical escape --- which is the whole point of the pin.

\textbf{The two gap models are the same algebra read two ways.} Pinned
reads the position class from the kernel-verified partition and applies
only the charged-glyph test inside TIER3. Auto reads both class and
severity directly off the glyph tuple plus the local contact count. Run
04 shows auto recovering most of the pinned shape on its own (135 gap-4
mutants versus 6 pinned --- auto over-assigns gap 4 to high-movement
mutants with ≥2 contacts, while the pinned table withholds). Run 10
shows the boundary cases of each rule in isolation: CORE4→4 only for the
six pins, TIER3→3 if charged, BASE→2 always; auto→4 if
\texttt{d≥3\ and\ b≥3} at ≥2 contacts, →3 if charged or \texttt{d≥2.5}
at 1 contact, →2 otherwise. Both readings terminate and both close B4=T
on the same 570-mutant landscape.

\textbf{The thresholds are real gates, not formatting.}
\texttt{-\/-top-conf} changes \emph{who is eligible} (run 05: widens
eligibility, same winner), and run 19 shows it can even change the
\emph{identity} of the winner once gap-4 mutants at confidence 0.60
enter the pool (the top becomes position 2, P→A).
\texttt{-\/-counter-conf} moves the engagement verdict between
``engages'' and ``does NOT engage'' on an unchanged computed confidence
(runs 01/06), and a non-canonical counter gets a \emph{computed}
7-bottleneck confidence (run 07: 0.512). Run 18 shows the gate refusing
when the landscape genuinely contains nothing eligible (no gap-4 tier,
all confidences ≤ 0.471 \textless{} 0.50).

\textbf{The vector build is an exact codec, not a lookup.} Step {[}7{]}
assembles CDR3 + linker + counter, encodes it using the first codon of
each residue, and asserts \texttt{translate(dna)\ ==\ payload} --- 29
amino acids → 87 nt canonically, 33 amino acids → 99 nt with the custom
counter, both round-tripping. The codon-viable count (180/570 canonical,
134/418 custom) is the same machinery applied to the WT side: a mutant
counts as low-risk if its residue sits in the single-nucleotide
neighbourhood of the max-neighbourhood WT codon (run 10:
\texttt{\_neighbors(\textquotesingle{}ATT\textquotesingle{})} gives 8
residues).

\textbf{Every input lane works, and every failure is typed.}
\texttt{-\/-wt} (01, 02, 17), \texttt{-\/-wt-file} FASTA with header
stripping (08), contact overrides with ranges (03), explicit gap model
(04, 19), short sequences through the non-windowed render path (09), and
all eight validation refusals with clean exit-2 semantics (11--15, empty
WT, 20--23). \texttt{-\/-help} documents the full surface (16).

\hypertarget{findings-where-the-suite-exposes-tension}{%
\subsection{6. Findings --- where the suite exposes
tension}\label{findings-where-the-suite-exposes-tension}}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{The default \texttt{-\/-top-conf} is model-dependent.}
  Auto-mode confidences top out at 0.60 (gap-4) and
  \texttt{0.45+0.001·pos} otherwise. A single hard default would be
  wrong for one of the two models; the per-model default (auto → 0.60)
  makes the tool's own auto mode reachable out of the box.
\item
  \textbf{The canonical convention guard is scoped to the model it
  encodes.} The guard fires only under
  \texttt{gap\_mode\ ==\ \textquotesingle{}pinned\textquotesingle{}}.
  Under auto gaps the top is
  \texttt{(2,\ \textquotesingle{}A\textquotesingle{},\ 4)} (runs 04,
  19), which is a legitimate auto-mode answer; scoping the guard to
  pinned mode means canonical + auto completes and reports the auto
  answer.
\item
  \textbf{Coverage 100\% under auto is by construction --- and run 03
  proves the distinction matters.} \texttt{autodetect\_contacts} puts
  every even position in CDR1 and every odd in CDR2, so CDR1∪CDR2 is the
  whole epitope and step {[}8{]} cannot report below 100\% for
  autodetected inputs (runs 02, 04, 09, 17: 382/382, 508/508, 173/173,
  382/382). It is only informative on canonical (193/193, where the
  contacts are real) or explicit-override inputs --- and run 03 is the
  witness: sparse overrides covering only positions 0--6 yield a
  \emph{measured} \texttt{115/151\ —\ 76\%}, with the 36 uncovered gap≥3
  mutants living outside the contact window.
\item
  \textbf{stderr/stdout interleave is an artifact, not a bug.} In run 18
  the error line appears \emph{before} the pipeline header in captured
  output; the gate executes after steps {[}1{]}--{[}4{]} --- unbuffered
  stderr simply overtakes buffered stdout under
  \texttt{2\textgreater{}\&1}.
\end{enumerate}
