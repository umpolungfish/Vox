# RSA-270 carrier diagnostics

The source is the exact decimal recorded in `../nested_carrier_validation.md`.
The executable bakes both its native numeral and the corrected nine-stage
operation word. It accepts no runtime source argument.

The original corrected executable was sampled with Vox `profile-native` for
90 seconds. The process ended with timeout status 137, with empty factor
output. `native.samples.tsv`, `vox.disasm`, `membrane.imasm`, and `hotspots.txt`
retain the matched instruction evidence. The hottest loop ranges occur in
numeral folding and unfolding.

Compile-time prefix diagnostics then executed each increasingly deep carrier
prefix for one and two rounds. The one-round prefixes all returned. The
two-round probe returned through P_PLUS but entered LEHMAN without returning
before its 25-second timeout. See `prefix_round2.stderr`.

Lehman previously swept the entire multiplier window inside one firing.
Its working register now retains `kn4`, the next candidate `a`, and `limit`.
Each firing tests at most 16 candidates, then returns to the nested
continuation. It advances the multiplier only after finishing the retained
window. It uses the same square and GCD checks as before.

The repaired two-round prefixes all returned, including LEHMAN, ECM, and FIX.
See `prefix_after.stderr`. The carrier suite passes all 37 tests, including
cursor retention across successive firings on the exact RSA-270 source.
`tests.stdout` records that run.

`membrane_resumable` is the retained repaired factoring executable. Its
30-second trial ended with timeout status 137 and empty factor output.
`resumable.stdout` and `resumable.stderr` are its output files.

## Wiring views

`wiring/index.html` is the full native circuit atlas of `membrane_resumable`,
generated by `render_membrane_diagram.py` using Vox `disasm --wiring`.
`wiring/circuit.json` and `wiring/vox.wiring.tsv` retain every recovered
instruction and explicit unresolved indirect port.

The dispatch function is at `79f80`; the resumable Lehman function is at
`8f4b0`. Open the viewer with `?function=79f80` or `?function=8f4b0` to inspect
those functions. These addresses apply only to this retained executable.

`carrier.svg` and `carrier.ascii` are the separate symbolic wiring of the
nine-stage operation word, generated by `render_carrier_diagram.py`. The
source numeral was never passed to that renderer as a program.

Diagnostic mode is baked with `FACTOR_DIAG_STAGES=1` and optionally
`FACTOR_DIAG_ROUNDS`. It reports prefix completion and returns without running
the unbounded factor workflow. Normal mode prints a pair only after exact
division and the independent product verification succeed.

The interim prefix executables and their native atlases were removed after
recording the comparison. The final executable, its complete atlas, the
symbolic diagram, and the original matched Vox samples are retained.
